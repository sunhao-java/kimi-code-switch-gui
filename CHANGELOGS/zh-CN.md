# 变更日志

本文件记录项目的重要变更。格式参考 Keep a Changelog，当前项目采用 `major.minor.patch` 版本号方案。

## [2.1.0] - 2026-06-08

### 新增

- **用量洞察（Usage Insights）**：通过解析 kimi-code-cli 的日志文件（`~/.kimi/logs/kimi.log`）自动统计 Token 用量、缓存命中率、推理耗时、调用趋势和会话分析，数据本地存储不上传。
- **配置历史版本控制**：每次保存配置时自动创建快照，支持按文件类型查询历史版本、查看 diff 并一键回滚。
- **成本估算系统**：为每个模型配置定价（输入/输出/缓存读取/缓存写入），洞察总览页实时展示预估花费。
- **多币种成本展示**：支持 CNY、USD、EUR、JPY、GBP 五种货币，自定义汇率，洞察页自动换算并展示。
- **洞察数据清除二次确认**：清除所有洞察数据前弹窗展示将清空的数据类型（事件记录/聚合统计/日志进度），避免误操作。

### 变更

- 洞察功能全面国际化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES），包括趋势图、分组统计、会话分析、设置页、Toast 提示、首次运行向导、清除数据对话框等所有界面元素。
- 币种选择器改用国旗标识 + 简洁标签，布局更紧凑直观。

### 修复

- 修复洞察趋势图缺失 `maxVal` 定义导致图表渲染崩溃的 bug。
- 修复侧边栏背景色在某些主题下截断的问题。
- 删除冗余的 `ConfigHistoryState` 结构体和 i18n 重复键。

## [2.0.1] - 2026-06-06

### 新增

- **Profile 中心视图**：Profiles 标签页重构为以 Profile 为核心的视图，可直观看到每个 Profile 绑定的渠道与模型，并在列表中直接切换激活 Profile。
- **向导式创建 Assistant**：新增 3 步向导（选渠道 → 测试连接 → 命名），从零开始一键创建完整可用配置，无需手动分别配置 Provider / Model / Profile。
- **级联删除引导**：删除 Provider 或 Model 前自动分析影响范围，弹窗展示将被连带删除的模型与 Profile，支持选择降级方案或确认删除。
- **Provider 健康状态 banner**：配置页顶部在检测到不可用渠道时实时提示，方便快速定位配置问题。

### 变更

- 向导内置渠道名称与描述全面国际化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）。
- 模型选择下拉样式优化，Profile 标签切换按钮收窄，界面更紧凑。

### 修复

- 修复级联删除后当前选中 Profile / Provider / Model 状态错乱的问题（Immer 回调内 `setState` 在 React 18 StrictMode 下被双调用）。
- 修复在空状态下打开级联删除预览时的崩溃问题（`getCascadePreview` 缺少 null 守卫）。
- 修复向导第三步允许创建与现有 Profile 同名配置的问题，现在会实时检测重名并禁用提交。

## [2.0.0] - 2026-06-01

### 新增

- 系统托盘右键菜单支持实时切换语言、主题与 Profile，切换后界面立即生效，无需重启。
- 左侧导航栏折叠/展开改为平滑过渡动画。

### 变更

- **架构重写：从 Electron 迁移到 Tauri v2（Rust + 系统 WebView）。** 采用「薄 Rust 壳 + 前端业务逻辑」架构，约 5300 行 `src/shared/` 业务逻辑近乎零改动复用；文件读写、命令执行、HTTP 请求、SQLite、系统托盘等系统能力改由 Rust 命令暴露。
- 安装包大幅瘦身：不再内置 Chromium 运行时，改用系统 WebView，macOS DMG 与 Windows NSIS 安装包体积显著减小。
- 标题栏改用 macOS 原生 Overlay 模式，红绿灯按钮由系统在标题栏内垂直居中绘制。
- 工程命名归一化：Vite 配置 `vite.config.ts`、构建输出目录 `dist/`、发布工作流 `release.yml`（触发标签由 `tauri-v*` 改为 `v*`）。

### 修复

- 修复 WebDAV 地址测试在认证失败 (401/403) 与限流 (429) 时缺少可读提示的问题。
- 修复从系统托盘切换语言/主题后界面不实时刷新的问题。
