# 変更履歴

本ファイルはプロジェクトの主要な変更を記録します。フォーマットは Keep a Changelog に準拠し、`major.minor.patch` のバージョン体系を採用しています。

## [2.1.2] - 2026-06-10

### 変更

- トレイとグローバルショートカットモジュールのデバッグログと重複コードを整理し、実行時のログノイズを削減。
- GitHub Release のタイトルをバージョン番号に固定し、リリース本文を CHANGELOG の内容から統一的に生成するように変更。

### 修正

- 「変更後バックアップ」と「定期バックアップ」戦略が作動しない問題を修正：設定保存後にコア設定のフィンガープリントに基づき重複を排除して静かにバックアップし、さらに定期スケジュール（毎時/毎日/毎週）で戦略に従って自動実行するようにしました。

## [2.1.1] - 2026-06-09

### 変更

- **表示/非表示ショートカット**：デフォルトで有効化し、既定のキー割り当てを `Command+Shift+H` に変更。
- **エージェント協業ガイド**：`AGENTS.md` を更新し、現在の Tauri v2 アーキテクチャ、コマンド、リリース制約に同期。

### 修正

- グローバルショートカットを録画/設定できず、再起動後に登録へ失敗する問題を修正。ショートカットは Rust メインプロセスで登録・処理され、ウィンドウ非表示時も安定して動作します。
- 表示/非表示ショートカットを押すと、ウィンドウが一度隠れてすぐ表示される点滅問題を修正。
- ショートカット録画がページ内ショートカットに干渉される問題を修正。録画処理は capture フェーズで捕捉し、組み合わせキーを正規化します。
- トレイへ隠した後、トレイメニューからウィンドウまたは使用状況インサイトを開いても Dock アイコンが復帰しない問題を修正し、残留するトレイイベントリスナーを整理。
- 構造化 SQLite `panel_settings` に対する設定履歴スナップショット/復元の互換性を修正。旧 schema 検出は `pragma_table_info` を使用します。

## [2.1.0] - 2026-06-08

### 追加

- **使用状況インサイト（Usage Insights）**：kimi-code-cli のログファイル（`~/.kimi/logs/kimi.log`）を解析し、Token使用量、キャッシュヒット率、推論レイテンシー、呼び出し傾向、セッション分析を自動集計。すべてのデータはローカルに保存され、アップロードされません。
- **設定履歴バージョン管理**：設定保存時に自動でスナップショットを作成。ファイル種別でのフィルタ、diffの閲覧、ワンクリックロールバックをサポート。
- **コスト見積もりシステム**：モデルごとに価格設定（入力/出力/キャッシュ読み取り/キャッシュ書き込み）を構成し、インサイト概要ページでリアルタイムにコストを表示。
- **多通貨コスト表示**：CNY、USD、EUR、JPY、GBP の5通貨をサポート。カスタム為替レートでインサイトページが自動換算・表示。
- **インサイトデータ消去の確認ダイアログ**：すべてのインサイトデータを消去する前に、消去対象（イベント記録/集計統計/ログ進捗）を表示し、誤操作を防止。

### 変更

- インサイト機能の完全国際化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）。傾向グラフ、分類統計、セッション分析、設定ページ、Toastメッセージ、初回実行ウィザード、データ消去ダイアログなどすべての UI 要素に対応。
- 通貨セレクターに国旗アイコン + コンパクトなラベルを採用し、レイアウトを簡潔化。

### 修正

- `maxVal` の定義不足によりインサイト傾向グラフがクラッシュする問題を修正。
- 一部のテーマでサイドバーの背景色が途切れる問題を修正。
- 冗長な `ConfigHistoryState` 構造体と i18n の重複キーを削除。

## [2.0.1] - 2026-06-06

### 追加

- **プロファイル中心ビュー**：Profiles タブをプロファイル起点のビューに刷新。各プロファイルに紐づくプロバイダーとモデルを一覧で確認でき、リストから直接アクティブ化できます。
- **アシスタント作成ウィザード**：3 ステップのウィザード（プロバイダー選択 → 接続テスト → 命名）で、Provider / Model / Profile を個別に設定する手間なく、完全な構成を一括作成できます。
- **カスケード削除ガイド**：Provider または Model を削除する前に影響範囲を自動分析し、連動して削除されるモデルとプロファイルをダイアログで表示。ダウングレードまたは削除の確認を選択できます。
- **プロバイダー健全性バナー**：到達不能なプロバイダーを検出すると設定ページ上部にリアルタイム通知を表示し、設定の問題を素早く特定できます。

### 変更

- ウィザード内蔵プロバイダー名・説明を全言語（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）に対応。
- モデル選択ドロップダウンのスタイルを改善。プロファイルタブ切り替えボタンをスリム化し、レイアウトをよりコンパクトに。

### 修正

- カスケード削除後に選択中の Profile / Provider / Model の状態が乱れる問題を修正（React 18 StrictMode で Immer プロデューサーが二重呼び出しされ、コールバック内の `setState` が二度実行されていた）。
- 空状態でカスケード削除プレビューを開くとクラッシュする問題を修正（`getCascadePreview` の null ガードが欠如）。
- ウィザードの最終ステップで既存プロファイルと同名の構成が作成できた問題を修正。入力中にリアルタイムで重複を検出し、送信ボタンを無効化するようになりました。

## [2.0.0] - 2026-06-01

### 追加

- システムトレイの右クリックメニューから言語・テーマ・プロファイルをリアルタイムに切り替え可能になり、UI が即座に反映されます（再起動不要）。
- サイドバーの折りたたみ／展開がスムーズなアニメーションになりました。

### 変更

- **アーキテクチャ刷新：Electron から Tauri v2（Rust + システム WebView）へ移行。** 「薄い Rust シェル + フロントエンドのビジネスロジック」構成を採用し、約 5,300 行の `src/shared/` のロジックをほぼ無改修で再利用。ファイル入出力、コマンド実行、HTTP リクエスト、SQLite、システムトレイなどは Rust コマンド経由で提供します。
- インストーラーを大幅に軽量化：Chromium ランタイムの同梱をやめてシステム WebView を利用し、macOS DMG と Windows NSIS のサイズを大きく削減。
- タイトルバーを macOS ネイティブの Overlay スタイルに変更し、信号機ボタンはシステムが上下中央に描画します。
- プロジェクトの命名を統一：Vite 設定 `vite.config.ts`、ビルド出力 `dist/`、リリースワークフロー `release.yml`（トリガータグを `tauri-v*` から `v*` に変更）。

### 修正

- WebDAV 接続テストで認証失敗 (401/403) とレート制限 (429) の際に読みやすいメッセージを表示するよう修正。
- システムトレイから言語／テーマを切り替えた後、UI がリアルタイムに更新されない問題を修正。

### 修正
