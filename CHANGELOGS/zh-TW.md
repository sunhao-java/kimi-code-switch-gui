# 變更日誌

本檔案記錄專案的重要變更。格式參考 Keep a Changelog，當前專案採用 `major.minor.patch` 版本號方案。

## [1.1.9] - 2026-05-25

### 新增

- 關於頁加入「目前版本變更」區塊，依介面語言渲染 `CHANGELOGS/{locale}.md` 目前版本段落，標題列右側提供「檢視所有版本」入口直接跳轉 GitHub Releases。
- 「檢查更新」對話方塊抓取並渲染新版本的 release notes（來自 GitHub Release body），一眼可見要升級的內容。

### 變更

- CHANGELOG 依語言拆分為 `CHANGELOGS/{zh-CN,zh-TW,en-US,ja-JP,de-DE,es-ES}.md` 六個檔案，頂層 `CHANGELOG.md` 改為索引；GitHub Release body 由 CI 合成中英雙語版本。
- 應用內 changelog 載入策略：首次啟動從 `raw.githubusercontent.com` 一次性抓取 6 份檔案快取到 `~/.kimi/.panel/changelog-cache/`，失敗時回退到打包內檔案；快取依目前 `app.getVersion()` 標記。
- 更新檢查主程序引入 `~/.kimi/.panel/release-cache.json`，帶 ETag 304 + 失敗兜底，緩解未驗證 GitHub API 60 req/h 限流。
- 關於頁移除寫死的「版本歷史」區塊及其 9 條 i18n 翻譯；版本歷史完整列表統一由「檢視所有版本」按鈕跳轉 GitHub。

### 修復

- 修復檢查更新對話方塊「新版本變更」區域內 `MarkdownView` 重複顯示版本號的問題：移除內部 panel header，僅保留外層標題。

## [1.1.8] - 2026-05-25

### 新增

- 外觀主題新增 5 款漸變方案：森林、櫻花、薄荷、星空、琥珀，配套亮暗雙套配色。
- Skill 詳情頁預設以渲染檢視展示 SKILL.md 內容，標題欄緊鄰複製按鈕新增 `</>` / `Eye` 圖示，可一鍵切迴帶行號的原始碼檢視。
- 用量洞察未啟用時，儀表盤空狀態新增「前往設定開啟」按鈕，直達設定 → 用量洞察子頁。

### 變更

- 用量洞察資料目錄遷移至 `~/.kimi/.panel/usage/`，啟動時自動遷移舊目錄 `~/.kimi/usage/`，新位置已存在資料時不覆蓋。
- 釋出前清理：移除未使用的 `mockttp` 依賴與相關程式碼，精簡 159 個傳遞依賴；安裝包預計減重 30–50 MB。
- 打包配置補齊：顯式宣告 `asarUnpack` 解包 `better-sqlite3` 原生模組，新增 `postinstall: electron-builder install-app-deps` 保證 CI / 新機器開箱可用。

### 修復

- 修復新增主題切換無效的問題：`parseAppearanceTheme` 與 preload 初始化白名單未同步包含新主題，導致選擇後被規範化回預設值或冷啟動閃爍。

## [1.1.7] - 2026-05-16

### 修復

- 恢復釋出流水線依賴的 `scripts/render_homebrew_cask.py`，修復 Homebrew tap 更新階段無法渲染 cask 的問題。

## [1.1.6] - 2026-05-16

### 變更

- 拆分主程序 IPC 與渲染層樣式模組，增強外部配置變更檢測和儲存前衝突處理。

### 修復

- 修復跨機器恢復備份時 Profile 路徑未遷移導致只剩預設 Profile 的問題。
- 修復頂部狀態列托盤圖示開關只儲存配置但不立即建立或移除托盤圖示的問題。
- 修復 macOS 下 Chromium CoreVideo display-link 噪聲日誌、配置列表全域性搜尋互動，以及錯誤邊界測試依賴缺失導致 CI 失敗的問題。

## [1.1.2] - 2026-05-09

- README 新增多頁面截圖和圖文功能介紹。
