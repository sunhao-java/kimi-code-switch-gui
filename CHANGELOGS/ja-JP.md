# 変更履歴

本ファイルはプロジェクトの主要な変更を記録します。フォーマットは Keep a Changelog に準拠し、`major.minor.patch` のバージョン体系を採用しています。

## [2.2.6] - 2026-08-31

### 追加

- **公式アカウントログインのキャンセル**：Kimi 公式アカウントのデバイスコードログインで認可待ちの間に、待機をキャンセルしてローカルの `kimi login` プロセスを停止できるようになりました。

### 修正

- **ログイン状態のクリア**：公式アカウントログインをキャンセルすると、認可 URL、ユーザーコード、有効期限を直ちに消去し、失効した認可情報を残さないようにしました。
- **安定性と UI フロー**：未保存変更の確認中に繰り返し操作すると確認を回避できる問題を修正。遅延読み込みダイアログにロード中のオーバーレイとエラー復旧を追加し、Overview ページが起動時に大きな About モジュールへ依存しないようにしました。

## [2.2.5] - 2026-06-17

### 変更

- **設定ページの Kimi Code セクションを再構成**：「Kimi Code インスタンス」「公式アカウント」「環境管理」の 3 つのサブメニューを単一の「Kimi Code」セクションに統合し、横方向タブで切り替える方式に変更。重複した見出しと枠を削除し、タブの下に機能説明を表示。さらにダークモードでの選択タブの配色を調整しました。
- **使用状況インサイトの更新が即時反映**：インサイトページの更新時に最新ログを先に取り込んでから集計するため、バックグラウンドのポーリングを待たずに直近の使用状況を確認できます。

### 修正

- **セキュリティ強化**：HTTP プロキシの SSRF リスク（ループバック/内部アドレスを拒否）、設定パスの範囲外への書き込み/削除リスク、Windows での MCP テスト時のコマンドインジェクションを修正しました。
- **データ安全性**：保存時に複数行文字列（hooks スクリプトなど）のインデントが破損する問題、アクティブセッションの使用記録がまれに失われる問題、初回画面での高速保存が外部変更検出を回避しうる問題、異常時の環境移行でディレクトリを誤削除しうる問題を修正しました。
- **その他の修正**：Kimi Code が常に古いと表示される問題、パスに `/sse` を含む正当な HTTP MCP エンドポイントが除外される問題、検出の更新ボタンが再検出しない問題、インサイトページのアクセシビリティラベル 2 か所の欠落を修正しました。

## [2.2.4] - 2026-06-16

### 追加

- **Kimi Code 複数環境の管理**：`~/.kimi-code-switch-gui/.env` 配下で複数の Kimi Code 環境を作成、コピー、有効化、削除でき、`~/.kimi-code` のシンボリックリンク切り替えにより CLI と GUI が同じ現在環境を使用します。
- **トップバー環境スイッチャー**：メイン画面右上に Kimi Code 環境のクイック切り替えを追加しました。

### 変更

- **設定ページの体験を改善**：専用の Kimi Code 環境テーブルと作成ダイアログ、環境 ID の自動生成、有効環境の編集ロックを追加し、既定環境名を「默认环境」に変更しました。
- **環境ごとのデータ分離**：Profile、Provider、Model、MCP、設定履歴、使用状況インサイトを Kimi Code 環境単位で分離し、新しい空環境が別環境の古いデータを引き継がないようにしました。
- **パネルデータの分離**：GUI 専用データを `~/.kimi-code-switch-gui` に移動し、Kimi Code 自身の設定ディレクトリへの干渉を減らしました。
- **セレクト UI の統一**：モデル設定ウィザード、インポート方式、MCP ツール選択、インサイトのフィルターを共通のカスタムセレクトに統一しました。

### 修正

- Kimi Code 環境切り替え後に「設定ファイルが外部で変更された」と誤検知する問題を修正しました。
- GUI で選択した現在環境にターミナルの `kimi` コマンドが追従しない問題を修正しました。
- Kimi Code インスタンス設定ページに冗長な「パスとファイル」ブロックが残っていた問題を修正しました。
- Kimi Code 環境一覧の操作列で保存ボタンが既定でプレースホルダー表示される問題を修正し、その行に未保存の変更がある場合のみ表示するようにしました。

## [2.2.3] - 2026-06-15

### 変更

- **初回起動パフォーマンスを改善**：設定読み込み時に Kimi Code 検出、リモート最新バージョン確認、設定診断、Skills スキャン、バックアップ基準作成、非重要な移行処理を待たず、最初の操作可能画面をより早く表示します。
- **Kimi Code 検出をバックグラウンド化**：概要ページと設定ページは先に「検出中」状態を表示し、検出完了後にバージョン、インストール方法、状態を自動反映します。手動更新チェックでは引き続きリモート最新バージョンを取得します。

### 修正

- ネットワークが遅い場合や Homebrew の問い合わせが重い場合に、初回起動がバージョン検出で長時間ブロックされる問題を修正しました。

- **モデル設定ウィザードの強化**：モデル設定作成時にグローバルで一意な設定名を入力でき、エンドポイント URL の形式検証と疎通テストを行えるようにしました。

- **Kimi Code バージョン検出の改善**：起動時の検出結果を概要表示に再利用しつつ、手動更新チェックは引き続き利用できます。

### 修正

- Kimi Code のターミナル起動で未対応の `--config-file` フラグを渡していた問題を修正し、対応済みのモデル、YOLO、Plan フラグを使うようにしました。
- 使用状況インサイトでイベントが存在してもトレンドと分類統計が空になる問題を修正し、Kimi Code wire ログの取り込みを追加しました。

## [2.2.1] - 2026-06-14

- **バックアップと履歴スナップショットの安定性を向上**：設定履歴、パネル設定、MCP ストレージ、ファイルスナップショット処理を改善し、Kimi Code 標準パスでのバックアップと復元の信頼性を高めました。

## [2.2.0] - 2026-06-12

### 追加

- **Kimi Code 標準設定のサポート**：GUI は Kimi Code を唯一の設定対象として扱い、メイン設定、MCP 設定、Skills ディレクトリ、パネルデータを標準の `~/.kimi-code/` 配置に統一しました。
- **SQLite Profile ストレージ**：Profile、現在有効な Profile、パネル専用設定を `~/.kimi-code/.panel/app.db` に移行し、非標準の `config.profiles.toml` は書き込まなくなりました。
- **Kimi OAuth ログイン入口**：設定ページから Kimi Code 公式の `kimi login` デバイスコードフローを開始でき、失敗理由に応じた読みやすいメッセージを表示します。
- **完全な MCP JSON ビューア**：MCP ページに標準 `mcp.json` 全体を確認できるプレビューダイアログを追加し、ワンクリックコピーに対応しました。

### 変更

- **MCP 編集体験を刷新**：stdio / http 用の専用フォームを追加し、引数、環境変数、リクエストヘッダーは行番号付きコードエディタで編集できます。既存 MCP の編集時は transport 種別をロックし、誤ったプロトコル変更を防ぎます。
- **Kimi Code 向けのパス、バックアップ、履歴対応**：設定履歴、バックアップ、Usage Insights、ドキュメントプレビューを Kimi Code 標準ファイルと SQLite パネルデータ中心に更新しました。
- **設定対象を Kimi Code インスタンスへ変更**：設定ページにバージョン、実行ファイル、解決パスを表示し、解決パスは読みやすいように 1 行を占有します。
- **概要ページの改善**：Profile カードと現在有効な Profile の概要はメイン設定モデルをフォールバック表示し、システム概要、設定パス、ダイアログのスクリーンをより一貫させました。

### 修正

- 空の `default_model` が設定診断で欠落モデル参照として誤報される問題を修正。
- `profile_label` が設定診断で未知フィールドとして誤報される問題を修正。
- MCP 完全 JSON ダイアログのスクリーンが GUI 全体を覆わない問題を修正。
- Homebrew パッケージ版で端末ログイン/起動時に AppleScript のキー送信権限が原因で失敗する問題を修正。

## [2.1.1] - 2026-06-09

### 変更

- **表示/非表示ショートカット**：デフォルトで有効化し、既定のキー割り当てを `Command+Shift+H` に変更。
- **エージェント協業ガイド**：`AGENTS.md` を更新し、現在の Tauri v2 アーキテクチャ、コマンド、リリース制約に同期。

### 修正

- グローバルショートカットを録画/設定できず、再起動後に登録へ失敗する問題を修正。ショートカットは Rust メインプロセスで登録・処理され、ウィンドウ非表示時も安定して動作します。

- ショートカット録画がページ内ショートカットに干渉される問題を修正。録画処理は capture フェーズで捕捉し、組み合わせキーを正規化します。
- トレイへ隠した後、トレイメニューからウィンドウまたは使用状況インサイトを開いても Dock アイコンが復帰しない問題を修正し、残留するトレイイベントリスナーを整理。
- 構造化 SQLite `panel_settings` に対する設定履歴スナップショット/復元の互換性を修正。旧 schema 検出は `pragma_table_info` を使用します。

## [2.1.0] - 2026-06-08

### 追加

- **使用状況インサイト（Usage Insights）**：kimi-code-cli のログファイル（`~/.kimi/logs/kimi.log`）を解析し、Token使用量、キャッシュヒット率、推論レイテンシー、呼び出し傾向、セッション分析を自動集計。すべてのデータはローカルに保存され、アップロードされません。
- **設定履歴バージョン管理**：設定保存時に自動でスナップショットを作成。ファイル種別でのフィルタ、diffの閲覧、ワンクリックロールバックをサポート。
- **コスト見積もりシステム**：モデルごとに価格設定（入力/出力/キャッシュ読み取り/キャッシュ書き込み）を構成し、インサイト概要ページでリアルタイムにコストを表示。
- **多通貨コスト表示**：CNY、USD、EUR、JPY、GBP の5通貨をサポート。カスタム為替レートでインサイトページが自動換算・表示。
- **インサイトデータ消去の確認ダイアログ**：すべてのインサイトデータを消去する前に、消去対象（イベント記録/集計統計/ログ進捗）を表示し、誤操作を防止。

### 変更

- インサイト機能の完全国際化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）。傾向グラフ、分類統計、セッション分析、設定ページ、Toastメッセージ、初回実行ウィザード、データ消去ダイアログなどすべての UI 要素に対応。
- 通貨セレクターに国旗アイコン + コンパクトなラベルを採用し、レイアウトを簡潔化。

### 修正

- `maxVal` の定義不足によりインサイト傾向グラフがクラッシュする問題を修正。
- 一部のテーマでサイドバーの背景色が途切れる問題を修正。
- 冗長な `ConfigHistoryState` 構造体と i18n の重複キーを削除。

## [2.0.1] - 2026-06-06

### 追加

- **プロファイル中心ビュー**：Profiles タブをプロファイル起点のビューに刷新。各プロファイルに紐づくプロバイダーとモデルを一覧で確認でき、リストから直接アクティブ化できます。
- **アシスタント作成ウィザード**：3 ステップのウィザード（プロバイダー選択 → 接続テスト → 命名）で、Provider / Model / Profile を個別に設定する手間なく、完全な構成を一括作成できます。
- **カスケード削除ガイド**：Provider または Model を削除する前に影響範囲を自動分析し、連動して削除されるモデルとプロファイルをダイアログで表示。ダウングレードまたは削除の確認を選択できます。
- **プロバイダー健全性バナー**：到達不能なプロバイダーを検出すると設定ページ上部にリアルタイム通知を表示し、設定の問題を素早く特定できます。

### 変更

- ウィザード内蔵プロバイダー名・説明を全言語（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）に対応。
- モデル選択ドロップダウンのスタイルを改善。プロファイルタブ切り替えボタンをスリム化し、レイアウトをよりコンパクトに。

### 修正

- カスケード削除後に選択中の Profile / Provider / Model の状態が乱れる問題を修正（React 18 StrictMode で Immer プロデューサーが二重呼び出しされ、コールバック内の `setState` が二度実行されていた）。
- 空状態でカスケード削除プレビューを開くとクラッシュする問題を修正（`getCascadePreview` の null ガードが欠如）。
- ウィザードの最終ステップで既存プロファイルと同名の構成が作成できた問題を修正。入力中にリアルタイムで重複を検出し、送信ボタンを無効化するようになりました。

## [2.0.0] - 2026-06-01

### 追加

- システムトレイの右クリックメニューから言語・テーマ・プロファイルをリアルタイムに切り替え可能になり、UI が即座に反映されます（再起動不要）。
- サイドバーの折りたたみ／展開がスムーズなアニメーションになりました。

### 変更

- **アーキテクチャ刷新：Electron から Tauri v2（Rust + システム WebView）へ移行。** 「薄い Rust シェル + フロントエンドのビジネスロジック」構成を採用し、約 5,300 行の `src/shared/` のロジックをほぼ無改修で再利用。ファイル入出力、コマンド実行、HTTP リクエスト、SQLite、システムトレイなどは Rust コマンド経由で提供します。
- インストーラーを大幅に軽量化：Chromium ランタイムの同梱をやめてシステム WebView を利用し、macOS DMG と Windows NSIS のサイズを大きく削減。
- タイトルバーを macOS ネイティブの Overlay スタイルに変更し、信号機ボタンはシステムが上下中央に描画します。
- プロジェクトの命名を統一：Vite 設定 `vite.config.ts`、ビルド出力 `dist/`、リリースワークフロー `release.yml`（トリガータグを `tauri-v*` から `v*` に変更）。

### 修正

- WebDAV 接続テストで認証失敗 (401/403) とレート制限 (429) の際に読みやすいメッセージを表示するよう修正。
- システムトレイから言語／テーマを切り替えた後、UI がリアルタイムに更新されない問題を修正。

- アップデート確認ダイアログが新バージョンのリリースノート（GitHub Release body から取得）を取得・表示するようになり、アップグレード内容を事前に確認できます。

### 修正

- アップデート確認ダイアログの「新バージョンの変更」ブロックで `MarkdownView` がバージョン番号を二重表示する問題を修正：内側のパネルヘッダーを非表示にし、外側のタイトルだけを残しました。
