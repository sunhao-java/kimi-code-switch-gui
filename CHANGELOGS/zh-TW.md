# 變更日誌

本檔案記錄專案的重要變更。格式參考 Keep a Changelog，當前專案採用 `major.minor.patch` 版本號方案。

## [2.1.1] - 2026-06-09

### 變更

- **顯示/隱藏快捷鍵**：預設啟用，並將預設鍵位調整為 `Command+Shift+H`。
- **代理協作指南**：更新 `AGENTS.md`，同步目前 Tauri v2 架構、命令與發布限制。

### 修復

- 修復全域快捷鍵無法錄製/設定、重啟後註冊失敗的問題：快捷鍵改由 Rust 主行程註冊與處理，視窗隱藏後仍可穩定回應。
- 修復按下顯示/隱藏快捷鍵時視窗先隱藏又立即顯示導致閃爍的問題。
- 修復快捷鍵錄製被頁面快捷鍵干擾的問題，錄製過程改為 capture 捕獲並統一規範化組合鍵。
- 修復隱藏到系統匣後，從系統匣選單開啟視窗或用量洞察時 Dock 圖示未恢復的問題，並清理系統匣事件監聽殘留。
- 修復設定歷史快照和恢復對結構化 SQLite `panel_settings` 的相容問題，舊 schema 偵測改用 `pragma_table_info`。

## [2.1.0] - 2026-06-08

### 新增

- **用量洞察（Usage Insights）**：透過解析 kimi-code-cli 的日誌檔案（`~/.kimi/logs/kimi.log`）自動統計 Token 用量、快取命中率、推理耗時、調用趨勢和會話分析，資料本機儲存不上傳。
- **設定歷史版本控制**：每次儲存設定時自動建立快照，支援按檔案類型查詢歷史版本、查看 diff 並一鍵回滾。
- **成本估算系統**：為每個模型設定定價（輸入/輸出/快取讀取/快取寫入），洞察總覽頁即時展示預估花費。
- **多幣種成本展示**：支援 CNY、USD、EUR、JPY、GBP 五種貨幣，自訂匯率，洞察頁自動換算並展示。
- **洞察資料清除二次確認**：清除所有洞察資料前彈窗展示將清空的資料類型（事件記錄/彙總統計/日誌進度），避免誤操作。

### 變更

- 洞察功能全面國際化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES），包括趨勢圖、分組統計、會話分析、設定頁、Toast 提示、首次執行精靈、清除資料對話框等所有介面元素。
- 幣種選擇器改用國旗標識 + 簡潔標籤，版面更緊湊直觀。

### 修復

- 修復洞察趨勢圖缺失 `maxVal` 定義導致圖表渲染崩潰的 bug。
- 修復側邊欄背景色在某些主題下截斷的問題。
- 刪除冗餘的 `ConfigHistoryState` 結構體和 i18n 重複鍵。

## [2.0.1] - 2026-06-06

### 新增

- **Profile 中心視圖**：Profiles 標籤頁重構為以 Profile 為核心的視圖，可直觀看到每個 Profile 綁定的渠道與模型，並在列表中直接切換啟用 Profile。
- **向導式建立 Assistant**：新增 3 步向導（選渠道 → 測試連線 → 命名），從零開始一鍵建立完整可用配置，無需手動分別設定 Provider / Model / Profile。
- **級聯刪除引導**：刪除 Provider 或 Model 前自動分析影響範圍，彈窗展示將被連帶刪除的模型與 Profile，支援選擇降級方案或確認刪除。
- **Provider 健康狀態 banner**：配置頁頂部在偵測到不可用渠道時即時提示，方便快速定位配置問題。

### 變更

- 向導內建渠道名稱與描述全面國際化（zh-CN / zh-TW / en-US / ja-JP / de-DE / es-ES）。
- 模型選擇下拉樣式優化，Profile 標籤切換按鈕收窄，介面更緊湊。

### 修復

- 修復級聯刪除後當前選中 Profile / Provider / Model 狀態錯亂的問題（Immer 回呼內 `setState` 在 React 18 StrictMode 下被雙呼叫）。
- 修復在空狀態下開啟級聯刪除預覽時的崩潰問題（`getCascadePreview` 缺少 null 守衛）。
- 修復向導第三步允許建立與現有 Profile 同名配置的問題，現在會即時偵測重名並停用提交。

## [2.0.0] - 2026-06-01

### 新增

- 系統匣右鍵選單支援即時切換語言、主題與 Profile，切換後介面立即生效，無需重啟。
- 左側導覽列收合/展開改為平滑過渡動畫。

### 變更

- **架構重寫：從 Electron 遷移到 Tauri v2（Rust + 系統 WebView）。** 採用「薄 Rust 殼 + 前端業務邏輯」架構，約 5300 行 `src/shared/` 業務邏輯近乎零改動重用；檔案讀寫、命令執行、HTTP 請求、SQLite、系統匣等系統能力改由 Rust 命令提供。
- 安裝包大幅瘦身：不再內建 Chromium 執行環境，改用系統 WebView，macOS DMG 與 Windows NSIS 安裝包體積顯著縮小。
- 標題列改用 macOS 原生 Overlay 模式，紅綠燈按鈕由系統在標題列內垂直置中繪製。
- 專案命名統一：Vite 設定 `vite.config.ts`、建置輸出目錄 `dist/`、發佈工作流 `release.yml`（觸發標籤由 `tauri-v*` 改為 `v*`）。

### 修復

- 修復 WebDAV 位址測試在驗證失敗 (401/403) 與限流 (429) 時缺少可讀提示的問題。
- 修復從系統匣切換語言/主題後介面未即時刷新的問題。
